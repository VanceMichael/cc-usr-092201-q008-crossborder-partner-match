# 跨境产业伙伴对接

保存跨境企业供需、保密对接和合作进展资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括企业档案、合作需求、能力证据、保密协议、会谈纪要、合作里程碑，状态示例为待匹配 → 已互选 → 待保密 → 会谈中 → 验证中 → 已结束。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 对接会汇聚多个国家和地区的企业
- 英国企业分别关注生产提效与医疗合作
- 企业希望通过大会寻找安徽本地伙伴

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
