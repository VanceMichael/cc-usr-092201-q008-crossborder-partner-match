# 跨境产业伙伴对接

保存跨境企业供需、保密对接和合作进展资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括企业档案、合作需求、能力证据、披露授权、保密协议、会谈纪要、修订记录、双方确认、合作里程碑、供需缺口，状态示例为待匹配 → 已互选 → 待保密 → 会谈中 → 验证中 → 已结束。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 对接会汇聚多个国家和地区的企业
- 英国企业分别关注生产提效与医疗合作
- 企业希望通过大会寻找安徽本地伙伴
- 仅留合作意向与名片无法推动后续跟进
- 企业档案需说清自身能力、待解决问题、合规边界、允许披露的材料及合作方式
- 必要条件相互满足后才开放联系人
- 技术细节在保密协议生效后才交换
- 翻译更正、需求改变、机构重复报名、代表离职与纪要分歧均以追加记录处理，不覆盖原记录
- 试验、尽调与采购进度由双方分别确认，任一方不能代替对方宣布完成
- 主办方依据双方确认辨别真实会谈、样品验证与合同进展
- 未成原因归纳成不泄露商业秘密的供需缺口

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明，并校验对接规则：企业档案具备自述五要素、条件互足才开放联系人、保密协议生效才交换技术细节、修订只追加不覆盖、里程碑需双方分别确认、供需缺口不点名企业。后续服务应继续兼容这份公开资料约定。
