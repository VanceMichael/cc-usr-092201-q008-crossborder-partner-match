# 跨境产业伙伴对接

保存跨境企业供需、保密对接和合作进展资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括企业档案、合作需求、能力证据、披露清单、合规声明、联系人开放记录、保密协议、会谈纪要、记录修订、合作里程碑、双方确认、供需缺口，状态示例为待匹配 → 已互选 → 联系人已开放 → 待保密 → 保密已生效 → 会谈中 → 验证中 → 尽调中 → 采购中 → 已成交 / 未成交。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 对接会汇聚多个国家和地区的企业
- 英国食品企业首次来华，在安徽寻找产线提效伙伴
- 同行医疗健康企业关注糖尿病和养老照护合作
- 企业希望通过大会寻找安徽本地伙伴
- 会后仅留下合作意向和名片无法推动需求落地

已约定的协作规则：

- 企业登记时须声明自身能力、待解决问题、合规边界、可披露材料与合作方式
- 必要条件相互满足后才开放联系人
- 技术细节在保密协议生效后才交换
- 翻译更正、需求变更、机构重复报名、代表离职与纪要异议以新记录追加，不覆盖原记录
- 试验、尽调、采购进度由双方分别确认，任一方不能代替对方宣布完成
- 未成原因归纳为不泄露商业秘密的供需缺口

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态、业务事实与协作规则。后续服务应继续兼容这份公开资料约定。
